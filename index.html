Element ID → BrickLink Converter

Paste LEGO Element IDs and quantities, get back a BrickLink Wanted List XML file ready to upload. Each ID is looked up against Rebrickable to find its matching BrickLink part and colour.

Get a free key at rebrickable.com/api. If "remember" is off, you'll need to paste it again next time.

One entry per line. Accepts 6248944 x1, 1x6248944, or 6248944x1 — order and spacing don't matter.

Your Wanted List XML and a per-line lookup report will show up here after you convert.
Runs entirely in your browser — IDs are sent only to the Rebrickable API for lookup, nothing is stored or sent anywhere else.
